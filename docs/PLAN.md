# WiPass 개발 계획

## 목표와 범위 (v1.0)

- 대상: 여러 장소에서 **와이파이 이름(SSID)은 같고 비밀번호만 다른** 무선망을 쓰는 학교 근무자 누구나
- 지원: WPA/WPA2/WPA3-개인(비밀번호만 입력하는 방식)
- 지원하지 않음: 802.1X(아이디+비밀번호), 비밀번호 없는 와이파이, 맥, 업데이트 알림, 설정 공유
- 선택 기능: 노트북 핫스팟 자동 켜기(기본 꺼짐, 설정에서 켬)
- 원칙: 인터넷으로 아무것도 보내지 않음 · 비밀번호는 PC에만 암호화 저장 · 관리자 권한 최소화

## 단계

| 단계 | 내용 | 상태 |

| 1 | 핵심 기능 시제품: 와이파이 제어(WLAN API), 장소·비밀번호 설정, 수동 전환, 진단 정보 저장 | ✅ v0.1.0-alpha.1~3 |
| 2 | 완성판: 자동 감지·학습(공유기 주소로 장소 판정, 처음 가는 장소는 비밀번호 차례로 시도), 윈도우 시작 시 자동 실행, 실행 파일 아이콘, 핫스팟 선택 기능 | ✅ v0.2.0-alpha.1 |
| 3 | 배포 준비: 설치 파일(Inno Setup), README 스크린샷, 이슈 양식 | ✅ v0.3.0-alpha.1~2 |
