## WiPass 0.3.0-alpha.1 — 3단계 시험판 (설치 파일)

### 새로 바뀐 점
- **설치 파일(`WiPass-Setup-0.3.0-alpha.1.exe`)** 을 제공합니다.
  - 관리자 권한 없이 지금 사용자에게만 설치됩니다. (`%LOCALAPPDATA%\Programs\WiPass`)
  - 시작 메뉴에 등록되고, 원하면 바탕화면 바로가기도 만듭니다.
  - 새 버전을 설치하면 실행 중인 WiPass를 닫고 바꿉니다. 장소와 비밀번호는 그대로 유지됩니다.
  - 윈도우 **설정 > 앱**에서 제거할 수 있고, 제거할 때 저장된 장소·비밀번호도 지울지 물어봅니다.
- 설치 없이 쓰는 **압축판(`-portable.zip`)** 도 함께 올립니다.
- 프로그램 위치가 바뀌면(압축판 → 설치판) 윈도우 시작 시 자동 실행 경로를 알아서 고칩니다.
- GitHub 문의 게시판에 **문제 신고 / 기능 제안 / 사용 문의** 양식을 만들었습니다.
- README에 설치·사용법·자주 묻는 질문을 정리했습니다.

### 압축판에서 설치판으로 옮기는 방법
1. 작업표시줄 WiPass 아이콘 → 종료
2. 설치 파일 실행 → 설치가 끝나면 WiPass가 바로 실행됩니다 (기존 설정 그대로)
3. 예전 압축판 폴더는 지워도 됩니다.
