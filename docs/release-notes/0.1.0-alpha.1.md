## WiPass 0.1.0-alpha.1 — 1단계 시험판

**제작자 확인용 시험판입니다.** 장소를 직접 골라 전환하는 기능만 들어 있습니다. (자동 감지는 2단계)

### 들어 있는 기능
- 처음 설정: 학교 와이파이 이름 고르기, 장소 이름·비밀번호 추가/수정/삭제
- 작업표시줄 아이콘: 상태 색 표시, 장소별 전환 메뉴
- 전환: 기존 와이파이 설정 삭제 → 장소 비밀번호로 등록 → 접속 → 결과 알림
- 접속에 성공하면 그 장소의 공유기 주소를 기억 (2단계 자동 감지에 사용)
- 도움말: 문의용 진단 정보 저장, 기록 폴더 열기, 위치 권한 설정 열기

### 사용법
1. `WiPass-0.1.0-alpha.1.zip`을 내려받아 압축을 풀고 `WiPass.exe` 실행
2. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]
3. 설정 창에서 와이파이 이름과 장소·비밀번호 입력 후 저장
4. 작업표시줄 아이콘 → 지금 있는 장소 선택
