## WiPass 0.7.0-alpha.2 — 스토어 제출용 패키지

- 파트너 센터에 등록한 앱 정보로 **스토어 제출용 패키지**(`WiPass-Store-…msix`)를 만듭니다.
  이 파일은 **파트너 센터에 올리는 용도**입니다. 서명이 없어 두 번 클릭해도 설치되지 않는 것이 정상입니다.
- 스토어 규칙에 맞게 패키지 버전 번호를 1.7.x.0 형식으로 바꿨습니다. (앱 안에 보이는 버전은 그대로 0.7.0)
- 기능 변경은 없습니다. 시험판(`WiPass-Test-…`) 설치 방법은 0.7.0-alpha.1 안내와 같습니다.
