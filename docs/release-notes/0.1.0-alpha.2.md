## WiPass 0.1.0-alpha.2 — 1단계 시험판 수정

### 바뀐 점
- **비밀번호가 틀렸을 때 더 빨리 알려 줍니다.** 윈도우가 비밀번호 오류를 보고하면 기다리지 않고 바로 실패를 알리고, 틀린 비밀번호로 계속 재시도하지 않도록 연결 시도를 멈춥니다. (최대 대기 25초 → 20초)
- **장소 추가·수정 방식을 바꿨습니다.** 목록 옆 [＋ 장소 추가] / [수정] / [삭제] 버튼을 누르면 작은 창이 뜹니다. 목록을 두 번 클릭해도 수정할 수 있습니다.
- 저장 버튼 이름을 [저장하고 닫기]로 바꾸고, 바꾼 내용을 저장하지 않고 닫으려 하면 한 번 더 묻습니다.
- 기록(진단 정보)에 접속까지 걸린 시간을 남깁니다.
