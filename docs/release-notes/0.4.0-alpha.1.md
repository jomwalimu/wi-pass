## WiPass 0.4.0-alpha.1 — 새 로고와 작업표시줄 아이콘

### 바뀐 점
- **새 로고**: 와이파이 물결을 옆으로 눕혀 앞으로 나아가는 모양(▶) — "도착하면 그대로 통과"라는 뜻입니다. 앱 아이콘, 설치 파일, 시작 메뉴가 모두 새 로고로 바뀝니다.
- **작업표시줄 아이콘을 윈도우 11 방식으로**: 색깔 원 대신 단색 기호를 쓰고, 오른쪽 아래 작은 **점**으로 상태를 알려 줍니다.
  - 초록 = 연결됨 · 노랑 = 전환 중 · 빨강 = 실패 · 점 없음 = 학교 와이파이 아님
  - 작업표시줄이 어두우면 흰색, 밝으면 검은색으로 자동으로 바뀝니다. 화면 배율에 맞춰 선명하게 그립니다.
- **설치 화면**에 WiPass 그림을 넣었습니다.
- README에 배너와 배지를 넣었습니다.

### 업데이트
새 설치 파일을 실행하면 됩니다. 장소와 비밀번호는 그대로 유지됩니다.
작업표시줄에 예전 아이콘이 남아 보이면 WiPass를 한 번 종료했다가 다시 실행해 주세요.
