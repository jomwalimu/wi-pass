## WiPass 0.6.0-alpha.1 — 새 화면 (빠른 창 · 시작하기 · 설정)

### 바뀐 점
- **아이콘을 누르면 빠른 창**: 시계 위에 윈도우 11 스타일의 작은 창이 열립니다.
  - 지금 어느 장소에 연결됐는지 크게 보여 주고, **장소 버튼 한 번**으로 바꿉니다. (현재 장소에 ✓)
  - **도착하면 자동 전환 / 노트북 핫스팟**을 바로 켜고 끕니다. 핫스팟이 켜져 있으면 핫스팟 이름과 연결된 기기 수도 보여 줍니다.
  - 창 밖을 누르거나 `Esc`로 닫힙니다. 오른쪽 클릭 메뉴는 그대로 있습니다.
  - 알림의 **[장소 고르기]** 버튼도 이 창을 엽니다.
- **처음 실행은 3단계 시작하기 창**: ① 와이파이(주변 목록에서 고르기, 보안 방식 표시) → ② 장소 → ③ 마무리(위치 권한 확인, 옵션).
- **새 설정 창**: 왼쪽 메뉴 **장소 · 옵션 · 정보·문의**.
  - 장소마다 알아 둔 공유기 수와 마지막 연결 시각, 지금 연결된 장소에 **"지금 여기"** 표시
  - 수정·삭제는 장소 옆 버튼으로, 학교 와이파이 이름은 **[변경]** 으로
  - **바꾸면 바로 저장** — 저장 버튼이 없습니다.
  - 옵션 맨 위에 위치 권한 상태를 보여 주고, 꺼져 있으면 **[켜러 가기]** 로 바로 엽니다.
- 윈도우가 **어두운 모드**면 모든 창이 어둡게 바뀝니다. (제목 표시줄 포함)

### 업데이트
새 설치 파일을 실행하면 됩니다. 장소와 비밀번호는 그대로 유지됩니다.
