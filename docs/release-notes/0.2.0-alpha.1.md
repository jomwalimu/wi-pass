## WiPass 0.2.0-alpha.1 — 2단계 시험판

### 새 기능
- **도착하면 자동 전환**: 학교 와이파이가 보이는데 연결되지 않으면, 주변 공유기를 보고 어느 장소인지 판단해 그 장소 비밀번호로 접속합니다.
  - 처음 가는 장소에서는 저장된 비밀번호를 차례로 시도하고(최근에 쓴 순서), 성공하면 그 장소의 공유기를 기억해 다음부터 바로 접속합니다.
  - 집 등 다른 와이파이에 연결돼 있을 때는 아무것도 하지 않습니다.
  - 모두 실패하면 알림을 띄우고 5분 뒤에 다시 시도합니다. 절전에서 깨어나면 바로 다시 확인합니다.
- **윈도우 시작 시 자동 실행** (기본 켜짐)
- **노트북 핫스팟 자동 켜기** (선택, 기본 꺼짐): 학교 와이파이에 연결되면 윈도우 모바일 핫스팟을 켭니다. 장소를 바꾸면 핫스팟도 새 연결로 다시 켭니다.
- 설정 창에 **3. 옵션** 추가, 작업표시줄 메뉴에서도 자동 전환·핫스팟을 바로 켜고 끌 수 있습니다.
- 프로그램 아이콘

### 업그레이드
실행 중인 WiPass를 종료하고 새 `WiPass.exe`로 덮어쓰세요. 장소와 비밀번호는 그대로 유지됩니다.
