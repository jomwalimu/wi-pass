## WiPass 0.7.0-alpha.1 — 마이크로소프트 스토어 준비 (시험판)

### 바뀐 점
- **스토어판(MSIX) 시험 패키지**를 함께 만듭니다. `WiPass-Test-…msix`는 스토어 제출 전 시험용입니다. **일반 사용자는 지금처럼 `WiPass-Setup-…exe`를 쓰세요.**
- 와이패스를 **다시 실행하면**(시작 메뉴 등) "이미 실행 중" 창 대신 **빠른 창**이 열립니다.
- 스토어판에서는 윈도우 시작 시 실행을 윈도우의 **시작 앱** 기능으로 관리합니다. 시작 앱에서 꺼 두면 그 설정을 따릅니다.
- 스토어판을 설치했는데 예전 설치판이 남아 있으면 제거하라고 알려 줍니다. (장소·비밀번호는 그대로 이어집니다)

### 시험판 설치 (스토어 시험용, 한 번만)
1. `WiPass-Test-0.7.0-alpha.1.cer`를 내려받아 두 번 클릭 → **인증서 설치** → **로컬 컴퓨터** → **모든 인증서를 다음 저장소에 저장** → **신뢰할 수 있는 사람** → 마침
2. `WiPass-Test-0.7.0-alpha.1.msix`를 두 번 클릭 → **설치**
3. 시험이 끝나면 시험판을 제거하고, 인증서도 지워 주세요. (`certlm.msc` → 신뢰할 수 있는 사람 → 인증서 → "WiPass Test" 삭제)
