## WiPass 0.6.0-alpha.2 — 빠른 창이 닫히지 않게

### 고친 점
- 빠른 창에서 **장소를 바꾸거나 자동 전환·핫스팟을 켜고 끌 때 창이 닫히던 문제**를 고쳤습니다.
  이제 창 밖을 누르거나 `Esc`, 작업표시줄 아이콘을 다시 누를 때만 닫힙니다.
  - 창을 새로 그리지 않고 글자·체크·토글만 바꾸도록 바꿨습니다.
- 빠른 창이 열려 있는 동안에는 "연결됨" 같은 안내 알림을 띄우지 않습니다. (알림이 빠른 창을 가리던 문제) 실패·경고 알림은 그대로 뜹니다.
- 전환 중에 다른 장소를 눌러도 "전환 중입니다" 알림이 뜨지 않습니다. 빠른 창 위쪽에 진행 상태가 보입니다.

### 바뀐 점
- 핫스팟에 **연결된 기기 수**는 보여 주지 않습니다. 핫스팟이 켜졌는지와 핫스팟 이름만 보여 줍니다.
