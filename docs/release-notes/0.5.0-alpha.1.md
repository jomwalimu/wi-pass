## WiPass 0.5.0-alpha.1 — 윈도우 알림과 새 메뉴

### 바뀐 점
- **정식 윈도우 알림**: 큰 파란 ⓘ 풍선 대신, 와이패스 아이콘이 붙은 윈도우 알림으로 바뀝니다.
  - 실패 알림에는 **[장소 고르기] [비밀번호 확인]** 버튼이 있어 바로 조치할 수 있습니다.
  - 위치 권한·핫스팟 문제 알림에는 **[위치 설정 열기] [핫스팟 설정 열기]** 버튼이 있습니다.
  - 알림 센터에는 WiPass 알림이 하나만 남도록 새 알림이 이전 알림을 대신합니다.
  - 설치판에서만 동작합니다. 압축판은 시작 메뉴 등록이 없어 기존 풍선 알림을 그대로 씁니다.
- **윈도우 11 스타일 메뉴**: 둥근 모서리, 둥근 선택 표시, 얇은 구분선, 넓은 간격. 윈도우가 **어두운 모드**면 메뉴도 어둡게 바뀝니다.
- 메뉴 맨 위에 **현재 장소(굵게)** 와 **자동 전환·핫스팟 상태**를 보여 줍니다.
- 문구를 자연스럽게: "왕북초(으)로 전환" → **"왕북초로 전환"**, "본관으로 전환"처럼 받침에 맞춰 바뀝니다.

### 업데이트
새 설치 파일을 실행하면 됩니다. (윈도우 알림이 동작하려면 설치판이 필요합니다)
