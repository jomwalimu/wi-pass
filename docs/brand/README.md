# WiPass 브랜드

## 로고 (A안 "앞으로 신호")

와이파이 물결을 옆으로 눕혀 앞으로 나아가는 화살표(▶)처럼 읽히게 한 기호입니다. "도착하면 그대로 통과"라는 뜻을 담았습니다.

| 파일 | 용도 |
|---|---|
| `logo.svg` | 기본 로고 (청록) |
| `app-icon.svg` | 앱 아이콘 원본 (청록 타일 + 흰 기호) |
| `../images/banner.png` | README 배너 |
| `../images/social-preview.png` | GitHub 미리보기 이미지 (저장소 Settings → Social preview에 올림) |

비트맵 자산(앱 아이콘 .ico, 설치 화면 그림, 배너)은 `tools/brand/make_assets.py`로 다시 만들 수 있습니다.

## 색

| 이름 | 값 | 쓰임 |
|---|---|---|
| 대표 청록 | `#0F766E` | 로고, 앱 아이콘, 강조 |
| 진한 청록 | `#134E4A` | 밝은 바탕 위 제목 |
| 밝은 청록 | `#5EEAD4` / `#99F6E4` | 어두운 바탕·청록 바탕 위 강조 |
| 바탕 | `#F0FDFA` | 배너·안내 바탕 |

## 작업표시줄 아이콘

- 단색 기호: 어두운 작업표시줄에서는 흰색, 밝은 작업표시줄에서는 검정(`#1F1F1F`)으로 자동 전환
- 상태 점(오른쪽 아래): 초록 연결됨 · 노랑 전환 중 · 빨강 실패 · 점 없음 = 학교 와이파이 아님

## 작은 크기 규칙

16px 이하에서는 가장 안쪽 물결을 빼고 선을 굵게 해서 뭉개지지 않게 합니다.
