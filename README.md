# 와이패스 (WiPass)

**같은 이름 학교 와이파이 자동 전환** — 윈도우 작업표시줄 프로그램

여러 학교(장소)의 와이파이 **이름은 똑같은데 비밀번호만 다를 때**,
학교를 옮길 때마다 "기존 와이파이 삭제 → 비밀번호 다시 입력"을 하고 계셨다면 WiPass가 대신해 드립니다.

> ⚠️ **지금은 1단계 시험판(알파)입니다.** 장소를 직접 골라 전환하는 기능만 들어 있고,
> 도착하면 알아서 바꿔 주는 자동 감지는 다음 단계에서 추가됩니다. → [개발 계획](docs/PLAN.md)

---

## 이런 분께 필요합니다

- 2개 이상의 학교·기관을 오가며 **개인 윈도우 노트북**으로 일하는 분
- 장소마다 와이파이 **이름이 같고**, **비밀번호만** 다른 경우 (예: 교육청 공통 무선망)

### 지원하지 않는 경우

- 아이디와 비밀번호를 함께 입력하는 와이파이 (802.1X, 엔터프라이즈 방식)
- 장소마다 와이파이 이름이 다른 경우 (윈도우가 원래 알아서 처리합니다)
- 맥(Mac), 아이폰, 안드로이드

## 설치와 사용 (시험판)

1. [Releases](https://github.com/jomwalimu/wi-pass/releases)에서 최신 `WiPass-버전.zip`을 내려받아 압축을 풉니다.
2. `WiPass.exe`를 실행합니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 **[추가 정보] → [실행]** 을 누르세요. (서명하지 않은 개인 제작 프로그램이라 뜨는 안내입니다)
3. 처음 설정 창에서
   - **학교 와이파이 이름**을 고르고
   - **장소 이름과 비밀번호**를 장소마다 추가한 뒤 **[저장]**
4. 작업표시줄 오른쪽(시계 옆, `^` 안쪽)의 와이파이 아이콘을 누르고 지금 있는 장소를 고르면, 그 비밀번호로 바꿔 접속합니다.

### 윈도우 위치 권한

윈도우 11 최신 버전은 위치 권한이 꺼져 있으면 주변 와이파이 정보를 프로그램에 알려 주지 않습니다.
**설정 > 개인 정보 및 보안 > 위치**에서 **위치 서비스**와 **데스크톱 앱이 위치에 액세스하도록 허용**을 켜 주세요.
WiPass는 위치를 기록하거나 어디로 보내지 않습니다.

### 아이콘 색

| 색 | 뜻 |
|---|---|
| 🟢 초록 | 학교 와이파이 연결됨 |
| 🟡 노랑 | 비밀번호를 바꿔 접속하는 중 |
| 🔴 빨강 | 접속 실패 — 메뉴에서 다시 시도하거나 비밀번호 확인 |
| ⚪ 회색 | 학교 와이파이 연결 안 됨 / 다른 와이파이 사용 중 |

## 개인정보와 보안

- 비밀번호는 **이 PC의 윈도우 계정으로만 풀 수 있게 암호화**(DPAPI)되어 저장됩니다.
- WiPass는 **인터넷으로 아무 정보도 보내지 않습니다.** (업데이트 확인, 사용 통계도 없음)
- 저장 위치: `%APPDATA%\WiPass` (설정 `settings.json`, 기록 `logs\wipass.log`)
- 지우려면 프로그램을 종료하고 위 폴더를 삭제하면 됩니다.

## 개발자용

- C# / .NET Framework 4.8 (WinForms), 윈도우 Native Wi-Fi API(`wlanapi.dll`) 사용
- 빌드: `dotnet build src/WiPass/WiPass.csproj -c Release`
- `VERSION` 파일의 버전을 올려 main에 반영하면 GitHub Actions가 빌드해서 Releases에 올립니다.
